## 四、已知会导致"看起来像存档失败"的既有设计（不是 bug）

- 标题页「继续游戏」在**没有任何存档时是禁用状态**（不会报错，只是点不动）。
- 「保存游戏」必须先进入游戏（`尚未开始游戏` 提示）。
- 覆盖已有槽位会先弹「覆盖存档？」，必须点**确认**才会真正写盘。
- 关窗退出走"先保存再退"，**保存失败时会停在"自动保存未完成"对话框**，此时可选「返回当前世界」或「放弃未保存进度并退出」——如果你的磁盘/权限有问题，就会看到这个框。

## 五、日志设计（新增）

### 1. 日志都落在哪里
统一目录：`%APPDATA%\Godot\app_userdata\泡沫年代 - Bubble Years\logs\`

| 文件 | 内容 | 生成方式 |
|---|---|---|
| `game.log` | 引擎日志：启动信息、所有 `ERROR`/`WARNING`、C# 异常栈、**游戏自己的"保存失败：xxx"/"读取存档失败：xxx"** | Godot `debug/file_logging`（已开启，保留 20 份） |
| `save-activity.log` | **存档动作监视**：启动自检 + 新建/更新/删除 每个存档文件（带大小与时间） | 移植版新增自动加载 `game\port\diagnostics.gd` |
| `godot*.log` | 引擎按次运行的滚动日志（旧版遗留，可忽略） | Godot 默认 |

### 2. 启动自检记录什么
每次启动在 `save-activity.log` 顶部写：
```
==================== 启动 2026-11-11 06:41:18 ====================
engine      : 4.7.2-stable (official)
os          : Windows / 10.0.19045
user://     : C:/Users/<你>/AppData/Roaming/Godot/app_userdata/泡沫年代 - Bubble Years/
exe         : <引擎路径>
cmdline     : []
DOTNET_ROLL_FORWARD : LatestMajor
save dir    : ...\saves (存在 / 不存在)
write test  : 正常 / [失败] <原因>
saves       : manual-1.json(872 B)、auto-1.json(764 B) …
```
出问题时先看 `write test` 与 `save dir` 两行——权限、路径、重定向类问题一眼可见。

### 3. 存档动作长什么样
```
[06:37:56] 新建  auto-1.json  764 B
[06:37:56] 新建  auto-1.json.parts/active/30f58...br  100063 B
[06:37:56] 删除  auto-1.json.parts/active/5bbb6...tmp
[06:38:01] 新建  manual-1.json  872 B
```
> `*.tmp` 被删除是正常的（写完会改名/清理）。

```
because a file or directory with the same name already exists.
```

| 文件 | 作用 |
