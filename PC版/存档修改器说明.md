# 存档修改器使用说明（图形界面版 / 命令行版）

> **推荐：`存档修改器.bat`（图形界面）** → `工具\SaveEditorGui\SaveEditorGui.exe`
> 命令行版：`存档修改器-命令行.bat` → `工具\SaveEditor\SaveEditor.exe`
> **务必先完全退出游戏再改**，改完后进游戏「读取存档」选对应槽位生效。

---

## 图形界面（v1.0.3 新增）

打开后：

1. 顶部选**槽位** → 点「读取」（141MB 世界需要几秒）
2. **基本信息** 页：天数、公司名、公司/个人现金、公司/个人债务
3. **员工** 页：
   - 左侧列表显示 **姓名 / 公司 / 岗位 / 满意度 / 六项能力**，点一行即在右侧编辑
   - 右侧：姓名、六项能力（0–999）、满意度（0–100）、月薪、**特质勾选列表**
   - 所有改动**即时生效**到内存（左侧列表会同步刷新）
   - 「六项能力 → 全员」把当前员工的能力套用到所有员工；「满意度 → 全员」同理
4. 「保存到该槽位」→ 自动备份清单 → 写盘（几秒）→ 进游戏读档

> 特质列表来自游戏内置目录（共 14 个，如 天才/势利眼/爱偷懒…），勾选即为拥有，取消即移除。
> 不会写入不存在的特质 ID，因此不会把存档改坏。

### 满意度锁定
右侧「满意度已锁定（不再随时间变化）」勾选框是**灰显说明**：
v1.0.3 已经把游戏里满意度的漂移系数从 `0.12` 改成 `0.0`，所以你在编辑器里填多少，
游戏里就**一直是那个值**（欠薪导致清零的规则仍保留）。

### 出错怎么办
- 保存失败弹窗会显示真实原因（如某条世界校验不通过），此时**没有写盘**，原档不变
- 保存前会自动备份到 `saves\.editor-backup-<时间>\`，把里面的 json 复制回槽位即可还原
- 也可以用 `存档修复.bat`（用 .bak 恢复）
- **界面打不开/空白**：看 `logs\editor.log`（该文件会记录启动异常）
- 自检命令：`工具\SaveEditorGui\SaveEditorGui.exe --uicheck manual-1`，会把控件状态写进 `editor.log`

> **v1.0.3 修复记录**：早期版本在控件还没有尺寸时就设置了 `SplitContainer.SplitterDistance/Panel2MinSize`，
> 导致窗体构造函数抛异常、界面直接打不开（表现为"看不到员工信息"）。现已改为在 `Shown` 事件里设置，
> 并默认停在「员工」页、启动后自动读取第一个可用槽位。

## 命令行版（旧）

> 工具：`存档修改器-命令行.bat` → `工具\SaveEditor\SaveEditor.exe`

## 一、能改什么

| 分类 | 字段 |
|---|---|
| 基本信息 | 天数、公司现金、个人现金、公司债务、个人债务、公司名称 |
| 员工（全部 276+ 人，含主角） | 姓名、六项能力（智力/魅力/口才/美术/音乐/技术）、满意度、月薪、岗位 |

改能力时会**同步**写入 `Abilities[]` 与对应的 `Design/Engineering` 字段，避免出现"显示了但计算用的是旧值"。

## 二、操作流程

1. 双击 `存档修改器.bat`
2. 先看列表确认槽位（`manual-1` / `auto-1` …）
3. 输入槽位（如 `manual-1`）回车
4. 主菜单：
   - `1` 基本信息 → 按编号改，改完 `0` 返回
   - `2` 员工 → 输入员工编号 → 改姓名/能力/满意度/月薪/岗位 → `0` 返回
   - `3` **保存并退出**（会重建分片，141MB 世界约需数秒）
   - `0` 放弃
5. 进游戏 → 「读取存档」→ 选该槽位

## 三、安全性

- 保存前会自动把该槽位的 `*.json / *.json.bak` 复制到 `saves\.editor-backup-<时间>\`
- 保存走游戏自己的 `SaveRepository.Write`（与游戏内保存同一条路径），会做世界校验；
  校验不通过会**直接报错且不写盘**，原存档保持不变
- 改数值建议保持合理范围（如现金不要给到 10^18 以上、能力 0–999、满意度 0–100）

## 四、关于"锁满意度"

游戏原本会让满意度每天向"目标值"缓慢漂移（系数 0.12），所以改完会慢慢回落。
v1.0.3 已在程序集里把该**漂移系数改为 0**（`BeginCareerDay` 里的 `* 0.12` → `* 0.0`），
因此：

- 编辑器里设成多少，游戏里就**一直是那个值**
- 员工不会再因为工资低/欠薪而掉满意度（欠薪时的 0 覆盖逻辑仍在，避免"欠钱还满满意度"）

> 想恢复原版漂移？把 `game\assemblies\original\BubbleYears.Simulation.dll` 覆盖回 `assemblies\patched\`
> 并重新 `dotnet build`（同时会丢掉"联网运营"存档修复，不建议）。

## 五、常见问题

| 现象 | 原因/处理 |
|---|---|
| 提示"槽位不存在或不可读" | 输错了槽位名；或该槽位是空槽 |
| 保存失败：`扩展存档：xxx` | 世界校验拒绝（把某项改成了非法值）。按提示改回合理值重试 |
| 保存很慢 | 正常：世界 JSON 141MB，需要序列化+压缩+重建分片 |
| 改完进游戏没变化 | 需要在游戏里**读取该槽位**（不是"继续游戏"读了别的档） |
| 想还原 | `saves\.editor-backup-<时间>\` 里的 json 复制回槽位；或用 `存档修复.bat` |

## 七、v1.0.4 修复记录（针对"改完存不上 / 特质选不了"）

| 现象 | 原因 | 处理 |
|---|---|---|
| 改能力后保存失败：`员工身份、能力或外观无效。` | 游戏对员工能力范围（约 10–60）与外观索引有校验，超出即抛异常 | 已在 `ValidateEmployees` 里**跳过该 throw**（仅这一处） |
| 给员工加多个特质后保存失败：`工作档案无效：员工特质数量` | 游戏限制 AI 员工"正面 ≤4 / 负面 ≤2" | 已把该 `Need(..., "员工特质数量")` 换成空实现 |
| 勾选特质没反应 / 像只能选一个 | 之前**没先选中员工**时勾选不会写入模型（`_sel` 为空直接返回） | 读档后**自动选中第一名员工**；未选中时勾选也会自动选中 |
| 满意度改完会变回去 | 每日漂移系数 0.12 | 已改为 `0.0` 并**重新并入统一补丁**（此前被整体重建覆盖过一次）；实测 4 个游戏日保持 `1.0` 不变 |

> 世界校验还有若干条（如 `扩展存档：近期运营回单`）。再遇到保存失败时，弹窗会给出**具体校验名**，发我即可按同样方式"只放开那一条"。

### 自检命令（排障用）
```
工具\SaveEditorGui\SaveEditorGui.exe --uicheck manual-1                  # 界面/数据自检 → logs\editor.log
工具\SaveEditorGui\SaveEditorGui.exe --selftest <存档目录> manual-1      # 改→存→回读验证
```

## 八、v1.0.5 变更

### 1) 存档跟着游戏走（便携化）
- 存档位置改为 **`PC版\game\saves`**（原来是 `%APPDATA%\Godot\app_userdata\...`）
- 整个 `PC版` 文件夹拷到别的电脑/U 盘即可继续玩，存档一起走
- 旧存档迁移：把 `%APPDATA%\Godot\app_userdata\泡沫年代 - Bubble Years\saves` 里的文件
  复制到 `PC版\game\saves` 即可（`settings.json` 放 `PC版\game\`）
- 修改器也会自动优先读取 `game\saves`

### 2) 只显示本公司员工
- 员工列表只显示 **企业编号 0（玩家公司）** 的员工，不再混入 AI 公司的几百人
- 主角也在其中

### 3) 一键完成全部科研
- 员工页底部新增按钮「一键完成全部科研」
- 效果：运行时/工具/制造/量化/效率 5 条科技线拉到目录允许的最高等级；
  清空进行中的科研项目；解锁全部软件特性与设备特性
- 点完后仍需「保存到该槽位」，进游戏读档才生效

### 4) 精简
- 只保留 `启动游戏.bat` 与 `存档修改器.bat` 两个批处理
- 移除了与游玩/修改无关的辅助脚本与工具（日志查看、诊断包、命令行版修改器、存档医生等）
